// 04.0 CODE OF ETHICS & DISCIPLINE

THE 10 COMMANDMENTS OF BACKEND CRAFTSMANSHIP

I.

Thou shalt not write silent catch blocks

Engolir exceções oculta corrupção de estado. Toda falha deve ser registrada com rastreamento de pilha completo ou tratada com idempotência.

II.

Thou shalt honor Clean Architecture

A camada de Domínio deve permanecer pura e desacoplada de frameworks, bancos de dados e protocolos externos.

III.

Thou shalt treat RCA as an exact science

Não aplique correções superficiais em sintomas; investigue a causa-raiz nos logs estruturados até isolar o vetor da falha.

IV.

Thou shalt crush human latency

Se uma rotina manual custa 6 minutos à equipe de atendimento, automatize o fluxo para milissegundos com C# assíncrono.

V.

Thou shalt design resilient queues

Mensageria distribuída com RabbitMQ deve prever dead-letter queues, retentativas exponenciais e consumidores idempotentes.

VI.

Thou shalt benchmark memory allocations

Alocações excessivas no heap desencadeiam pausas de Garbage Collector. Utilize `Span`, `ReadOnlyMemory` e streams sempre que aplicável.

VII.

Thou shalt index foreign keys

Queries sem índices causam table scans em tabelas massivas. Otimize o plano de execução antes de culpar o banco de dados.

VIII.

Thou shalt decouple read from write

Empregue CQRS com Dapper para leituras de ultra-alta velocidade e EF Core com regras de agregação para mutações críticas.

IX.

Thou shalt emit structured observability

Logs em texto puro dificultam diagnósticos distribuídos. Emita JSON com CorrelationId e métricas de telemetria integradas.

X.

Thou shalt build software that outlasts hype

Priorize robustez, testabilidade e clareza de engenharia sobre tendências passageiras do ecossistema.
